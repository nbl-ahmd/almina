There were no source-only patterns. Dynamic route patterns are not counts of concrete URLs or enabled capabilities. Static public assets/PWA resources and proxy redirects add compatibility surfaces beyond page counts.

AST test inventory finds **32 E2E spec files / 130 test declaration expressions**. Loops/templates expand these into other runtime case counts; no tests were run or passed by this inventory. Test titles/locations and source hints are indexed for selection, not proof of coverage quality. Source route/query/gate hints in JSON are deliberately partial; the policy tables below account for helper-driven behaviour.

Raw audit script/counts and Next route response: ignored `.verification-results/storefront-replacement/phase-0/p0-03-*`. No browser/session/server was started; existing preview retained. No login, cart mutation, order, database reset or provider operation performed.

# New reference review — 17 November 2026

Planning evidence only. These images expand the reference set; they do not approve a new palette, font, token system, service or screen. The current runtime and DESIGN.md remain unchanged by this review. New proposals belong in the accompanying [direction plan](storefront-direction-plan-2026-11-17.md) until reviewed on screens.

## Confirmed intent versus interpretation

**Owner requirements:** a coherent replacement system; mobile must look, feel and behave like an app; desktop must feel complete and professional; compact useful density, deliberate padding and whitespace; review the new references and provide a detailed plan. Existing confirmed commitments include the actual logo, exact primary accent #FF5A5F, search priority, English/Arabic/RTL, working previews and preserved commerce behaviour. No deployment.

**Our interpretation, proposed:** borrow the mobile references' task hierarchy and the desktop references' merchandising rhythm, rather than merge their visual styles. Keep coral for important shopping actions, use a quieter supporting canvas, and make imagery and factual product information carry the shelves. Do not import green/teal as another competing primary palette.

Seven files represent four design families, not seven independent directions: N02/N03 share a mobile concept; N04/N06/N07 share the desktop concept. N01 and N05 provide separate mobile treatments. Repetition is useful detail, not extra evidence of approval.

## N01 — Teal mobile home and product detail

[Image](../../../../docs/design/storefront/references/2026-11-17/01-teal-mobile-home-pdp.jpg)

- **Navigation/search/location:** clear location first, prominent search immediately below, compact utility icon. Bottom destinations have persistent labels. Borrow this hierarchy; avoid copying the oversized dark floating navigation capsule, raised active circle or notification/filter icons without matching functions. Adapt the real saved-area selector and existing cart/search into a stable mobile shell.
- **Product cards/discovery:** short category labels and image categories make browsing legible. Borrow clear separation between section heading, category row and product shelf. Avoid the pet-specific silhouettes and card content cut off by presentation chrome. Use actual Al Mina categories, not an invented taxonomy.
- **Product detail:** large gallery, thumbnail strip, identity, real options and a price/purchase dock form a strong sequence. Borrow gallery-to-buying continuity. Avoid seller avatar/chat/call controls, 360-degree indicator and rating unless supported by actual behaviour/data. Use existing pharmacy help and existing options only.
- **Cart/checkout:** the purchase dock is visible; subsequent basket and checkout are not shown. No inference about quote, stock, payments, validation or checkout speed is justified.
- **Type/colour/space/imagery:** one strong hue, white surfaces and a dark readable text hierarchy give coherence. Borrow disciplined role assignment and consistent pack framing. Do not import teal, pet photography or device dimensions as final Al Mina choices.
- **Unknown:** sticky/scroll behaviour, search keyboard, focus, selected size state, gallery gestures, saved-state feedback, back stack, keyboard/safe-area interaction, RTL and error/loading states.

## Synthesis for Al Mina

1. Mobile: stable location/cart context → wide search → bounded campaign → concise category row → complete purchasable cards. Page-specific detail/purchase docks replace, rather than stack with, global chrome when appropriate.
2. Desktop: compact unified header → shallow campaign plus useful discovery → aligned multi-product shelves → selective managed campaigns → purposeful footer. Each module needs actual content and a reason to exist.
3. Shared identity: one colour-role system, one paired language type system, one component anatomy and states. Mobile and desktop need distinct compositions with the same product truth.
4. Keep from previous owner requests: compact factual cards, dirham symbol, persistent purchase access, search priority. New references do not silently approve changing the exact coral or copying another business's services.
5. Test screen density using realistic long names, missing media, unavailable products, variable prices, Arabic and selected packs. Screenshot proportions are inspiration, not CSS specifications.

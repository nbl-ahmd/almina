# Native persistent database ownership

The persistent Express process now owns one explicit MongoDB 7.7.0 pool in maintained TypeScript. Both retained and versioned API contracts, current cookie sessions, readiness, checkout, signed webhook handling and notification workers receive that same database. Requests do not construct clients or reconnect a closed service. Startup connects and checks a writable transaction-capable primary before listening; shutdown drains HTTP/workers before closing the pool. Connection errors are redacted. Native pool/server selection/connect/socket/wait-queue limits remain bounded. Node 24 satisfies the driver's supported runtime requirement.

`client.db()` preserves the database selected by the existing URI, including the driver's default if none is specified. No new database name is inferred from environment or deployment labels. Neither install nor build opens a database. Native code has no ODM schema registration, automatic index creation, implicit defaults or collection initialization. Existing documents, unknown fields, schema defaults already persisted, historical indexes, identifiers, money, stock, order lines and receipts remain unchanged. Index/backfill/recovery apply commands are separate explicit maintenance operations. Recovery still requires disabled drafts, zero stock, no overwrite and a closed store.

Mongoose is removed from the backend runtime and lockfile after the preceding maintained query/write extractions. Routes use injected database ownership instead of an ambient ODM connection fallback. The retained paths remain compatibility adapters with independent server authorization. The standalone versioned fixture keeps its separate explicit environment/database mode; production uses the combined Express entry point. Separately installed backend/workspace BSON constructors require validated ObjectId normalization at DTO boundaries; strings and arbitrary object values remain rejected. Existing native writes/transactions and uncertain-provider receipts are preserved.

Implementation references: [MongoClient/database selection](https://www.mongodb.com/docs/drivers/node/current/connect/mongoclient/), [pool limits and close behavior](https://www.mongodb.com/docs/drivers/node/current/connect/connection-options/connection-pools/), [native options](https://www.mongodb.com/docs/drivers/node/current/connect/connection-options/).
